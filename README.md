## Анализ и прогноз ПЭС земной ионосферы
Данный репозиторий посвящен анализу и прогнозированию распределения полного электронного содержания (ПЭС) на основе сферических функций. 

Есть наблюдательные данные ПЭС, которые записывались с 1999 по 2022гг.. Вид исходных данных -- первые 256 коэффициентов разложения. Для обработки рядов использовался метод Берга (Метод максимальной энтропии), так как имеет высокую разрешающую способность. После построения спектральных плотностей мощности (Power Spectral Density) были извлечены значимые гармоники.

В первой гармонике ожидалось увидеть 11-летний солнечный цикл. Так и оказалось, период первой гармоники составляет приблизительно 12 лет.

В современных спутниковых системах используется модель Клобушара для учета ионосферной задержки. Она не является достаточно точной. Уже есть статьи, в которых используют модель на основе сферических функций. Она позволяет учитывать ионосферную задержку в несколько раз точнее, нежели модель Клобушара.
